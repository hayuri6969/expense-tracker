# Pennywise - Expense Tracker

A beginner-friendly personal finance dashboard made with HTML, CSS, and JavaScript.

## Features
- Track income and expenses in Philippine pesos (PHP)
- Automatically calculate total balance, income, and expenses
- Add transactions with a description, amount, category, and date
- Filter the transaction list by income or expenses
- Delete transactions
- Save data in browser localStorage

## Project files
- `index.html` - website structure
- `style.css` - layout, colors, and responsive design
- `script.js` - calculations, transaction features, and browser storage

## Run in Visual Studio Code
1. Download and extract `expense-tracker.zip`.
2. Open Visual Studio Code.
3. Select **File > Open Folder...** and choose the `expense-tracker` folder.
4. Open `index.html`.
5. Right-click in the editor and choose **Open with Live Server** if you have the Live Server extension.
6. Alternatively, double-click `index.html` in your file manager to open it in a browser.

## Run in Visual Studio
1. Select **File > Open > Folder...** and choose the extracted folder.
2. Open `index.html`.
3. Open the page in a web browser. No build step is required.

## How it works
- HTML creates the dashboard and form.
- CSS styles the dashboard and makes it responsive.
- JavaScript handles transactions and calculations.
- `localStorage` saves transactions in the current browser on the current device.

## Important
This is a front-end learning project. It does not connect to a bank or a real database. Clearing browser data may remove locally saved transactions.
